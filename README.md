# Longitudinal plasma proteomics defines a proteomic detection horizon and implicates NECTIN2 in neovascular AMD conversion



- `cox/`: cohort construction, covariate processing, and Cox regression scripts.
- `ML/`: participant-level five-fold LASSO stability selection and
  fold-specific 10-protein prediction.

The ML code runs on the authorized analysis-ready UK Biobank/Olink table. The
individual-level data are not redistributed.

The complete analysis is documented in [`ML/README.md`](ML/README.md); no
simulated data are required for the manuscript run.
